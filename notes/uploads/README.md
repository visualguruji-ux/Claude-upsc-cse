# 📥 Uploads — Adarsh's raw study material

Drop raw notes here for Claude to read and process (digitise, enrich, or turn
into Prelims drills).

## What to upload
- **PDF** — best for CollaNote / handwritten notes (keeps handwriting; supports OCR).
- **Images** (PNG / JPG) — good for single pages or screenshots.
- Plain text / Markdown — fine too.

## How to upload from iPad / browser
1. In **CollaNote**: open the note → **Share / Export** → choose **PDF** → save to Files.
2. On **github.com** → this repo → open `notes/uploads/` → **Add file → Upload files**.
3. Select the PDF/images → **Commit changes**.

## After uploading, tell Claude
- The **file name** you used.
- The **branch** you uploaded to (website uploads default to `main`).
- What you want done: **faithful digitisation**, **enriched one-stop note**, or a **Prelims MCQ drill**.

> Tip: name files descriptively, e.g. `sociology-thinkers-weber.pdf` or
> `polity-fundamental-rights-p1.jpg`, so they're easy to reference.
